# Experiment 9 — Neon Relic Run

An asset-free, complete interactive 3D mini-game made for the CG & VR lab.

To run it inside Unity, open this folder as a project in Unity 6.0.6.8f1 and press **Play**. The game creates its arena, neon lighting, player, 12 collectibles, portal, camera, sky, HUD, and win state at runtime—no scene wiring is needed.

- Move: **WASD** or arrow keys
- Sprint: **Left Shift**
- Jump: **Space**
- Win: collect every relic, then enter the portal
- Replay: **R**, after winning

The project deliberately uses only built-in Unity primitives and generated materials, so it needs no asset downloads or package setup after the editor is installed.
